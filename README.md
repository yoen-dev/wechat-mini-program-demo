# 三角洲护航小程序（模板版）

uni-app (Vue 3) 项目，同一套代码可以编译成**微信小程序**和**网页预览版**。

当前是**功能模板**：样式为中性灰白，后端用本地模拟数据（存在手机 / 浏览器里，刷新不丢），用于先把需求和流程跑通。设计定稿、后端接好后再替换。

## 在线预览

`https://yoen-dev.github.io/wechat-mini-program-demo/` （推送到 `main` 后自动部署）

### 演示账号

| 身份 | 怎么登录 |
| --- | --- |
| 用户 | 「我的 → 登录」→ 微信一键登录 → 绑定手机号，验证码固定 **123456**；或点登录页的「示例老板」直接登录 |
| 管理员 | `admin` / `admin123` |
| 客服 | `kefu01` / `123456` |
| 护航 | `hh01` / `123456`（还有 `hh02`、`hh03`） |

员工入口：「我的 → 员工登录」。数据只存在当前设备，「我的 → 重置演示数据」可恢复初始状态。

## 四种身份能做什么

**用户**：浏览单子 → 选规格（单次 / 三次 / 五次）→ 选客服派单或指定护航 → 填游戏 ID → 模拟支付 → 订单沟通 → 申请退款。浏览不用登录，下单和看订单时才要求登录。

**护航**：待处理（接 / 拒指定给自己的单、开始护航、完成订单）、抢单大厅（抢客服还没派出的单）、已完成、订单沟通。

**客服**：待派单（派单 / 改派）、退款（同意 / 拒绝）、进行中、全部订单、订单沟通。

**管理员**：数据概览（今日 / 累计订单和收入、待办）、全部订单（可派单、处理退款）、单子管理（新建、编辑价格和说明、上下架）、员工账号（新建护航 / 客服 / 管理员账号、重置密码、停用）。

员工都可以在「账号设置」里改密码、退出登录。

## 订单状态

```
待付款 ──支付──▶ 待派单（客服派单） / 待接单（指定护航）
待派单 ──客服派单 / 护航抢单──▶ 已接单
待接单 ──护航接单──▶ 已接单        ──护航拒单──▶ 待派单
已接单 ──开始──▶ 进行中 ──完成──▶ 已完成
待派单 / 待接单 / 已接单 ──申请退款──▶ 退款中 ──同意──▶ 已退款（拒绝则回到原状态）
待付款 ──取消──▶ 已取消
```

## 代码结构

```
src/
  api/            模拟后端（接真后端只改这里）
    db.js         本地“数据库”和种子数据
    auth.js       微信登录、短信验证码、绑定手机、员工登录、改密码
    products.js   单子、分类、规格
    orders.js     订单状态流转、聊天、统计
    staff.js      员工账号管理
  store/session.js  登录态、按身份跳转、页面守卫
  orderActions.js   各身份在各状态下能点哪些按钮（全端共用）
  components/       订单卡片、状态标签、员工页头等
  pages/
    index category detail orders order chat service me   用户端
    login/            登录、绑定手机号
    staff/            护航 / 客服 / 管理员工作台、单子编辑、新建员工、账号设置
```

## 本地开发

```bash
npm install
npm run dev:h5          # 浏览器预览
npm run dev:mp-weixin   # 用微信开发者工具导入 dist/dev/mp-weixin
npm run build:mp-weixin # 正式构建，导入 dist/build/mp-weixin
```

导入微信开发者工具前，把 `src/manifest.json` 里 `mp-weixin.appid` 填成公司小程序的 AppID。

## 接后端时要换的地方

- `api/auth.js`：`uni.login` 拿 code 换 openid；短信验证码走短信服务（或用微信「手机号快速验证」）；员工登录返回 token
- `api/orders.js`：`payOrder` 改为后端统一下单 + `uni.requestPayment`，状态以支付回调为准
- `pages/chat`：轮询改为 WebSocket 或云开发实时推送
- 上线前删除登录页的「演示账号」区块和「我的 → 重置演示数据」
